# Booking API (ABP Test Task)

API для управління бронюванням та орендою конференц-залів.

## Технології та Архітектура
- **.NET 10** (ASP.NET Core Web API)
- **PostgreSQL** + Entity Framework Core (Code-First)
- **CQRS Pattern** (через бібліотеку MediatR)
- **Domain-Driven Design (DDD)** (Ізольована логіка розрахунку вартості)

## Основні архітектурні рішення
1. **Ізоляція бізнес-логіки**: Складний алгоритм розрахунку ціни (ранкові, пікові, вечірні години) винесено в окремий доменний сервіс `IPricingCalculator`.
2. **Історичність цін**: Сутність `Booking` зберігає `TotalPrice` на момент бронювання (Snapshot). Якщо ціна залу зміниться в майбутньому, старі чеки не постраждають.
3. **Запобігання Overlap'у**: Логіка перевірки перетину часу бронювань інкапсульована в доменній сутності `Room`.
